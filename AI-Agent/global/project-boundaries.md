# Project Rules

## Architecture Rules
- Use .NET 8 Clean Architecture
- Use Service + Repository pattern
- DO NOT use CQRS
- DO NOT use MediatR
- Use Microsoft SQL Server with EF Core
- Use React + TypeScript
- Use Tailwind CSS
- Use React Query for API calls

---

## Authentication Rules
- JWT Access Token
- Refresh Token Rotation
- bcrypt password hashing
- Secure httpOnly cookies

---

## Frontend Rules
- Mobile-first responsive design
- Reusable components
- Proper loading states
- Proper error handling
- Accessibility support

---

## Backend Rules
- Centralized exception handling
- FluentValidation
- DTO-based communication
- Repository pattern
- Proper logging

---

## Forbidden Rules
- DO NOT use mock implementations
- DO NOT use unnecessary libraries
- DO NOT duplicate APIs
- DO NOT generate unused code
- DO NOT break existing modules

---

## Development Rules
- Only develop one module at a time
- Plan first before development
- Testing mandatory before moving modules
- KPI coverage required before completion
